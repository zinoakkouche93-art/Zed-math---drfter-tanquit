دفتر التنقيط – الزاد في الرياضيات

التحديث:
- أضيف صفّان لرؤوس الجدول، مع تجميع مؤشرات الأعمال داخل القسم والأعمال خارج القسم فوق مؤشرات كل مجموعة.
- تُدخل علامة الاختبار من 20، ويحوّلها التطبيق إلى /40 عند حساب المعدل الفصلي وفق الصيغة: (معدل التقويم المستمر + علامة الاختبار بعد مضاعفتها) ÷ 3.
- يمكن إضافة المؤشرات وحذفها وتعديل الاسم والعلامة القصوى والمجال من إعدادات المؤشرات.
- بيانات التطبيق تُحفظ محليًا في المتصفح. أنشئ نسخة احتياطية JSON قبل تحديث الملفات أو حذف بيانات المتصفح.

للنشر على GitHub Pages: ارفع محتويات هذا المجلد إلى المستودع نفسه، مع استبدال الملفات القديمة.
