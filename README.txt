دفتر التنقيط – الزاد في الرياضيات

التحديث:
- إضافة إدارة أقسام متعددة دون حد ثابت: إضافة قسم، اختيار قسم، إعادة تسميته، وحذفه بعد تأكيد المستخدم.
- لكل قسم قائمة تلاميذ وعلامات مستقلة، مع حفظ البيانات محليًا في المتصفح.
- إزالة الحد الثابت البالغ 40 تلميذًا عند الإضافة اليدوية أو الاستيراد.
- إضافة ترحيل تلقائي للبيانات القديمة إلى قسم أول عند فتح النسخة المحدّثة، مع الحفاظ على التلاميذ والعلامات الحالية.
- يمكن إضافة المؤشرات وحذفها وتعديل الاسم والعلامة القصوى والمجال من إعدادات المؤشرات.
- تُدخل علامة الاختبار من 20، ويحوّلها التطبيق إلى /40 عند حساب المعدل الفصلي وفق الصيغة المعتمدة في التطبيق.
- بيانات التطبيق تُحفظ محليًا في المتصفح. يُنصح بإنشاء نسخة احتياطية JSON قبل تحديث الملفات أو حذف بيانات المتصفح.

للنشر: ارفع محتويات هذا المجلد إلى المستودع نفسه، مع استبدال الملفات القديمة.
